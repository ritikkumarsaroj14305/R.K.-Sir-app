# R.K. Sir Education Android App

This is a ready-to-build Android app for Class 5th to 12th, using the supplied R.K. Sir logo.

## Build APK from phone
1. Upload this folder to a GitHub repository.
2. Open **Actions**.
3. Select **Build R.K. Sir APK**.
4. Tap **Run workflow**.
5. Download the `RKSir-APK` artifact and extract `app-debug.apk`.
